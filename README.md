# 행정사 암기카드 앱 (AdminMemoApp)

4개 과목(민법-계약법, 사무관리론, 행정사실무법, 행정절차론) PDF에서 자동으로
추출한 학습 카드가 들어있는 안드로이드 학습 앱입니다. 홈 화면 위젯도 포함되어
있습니다.

## 이 프로젝트로 APK 만들기 (Android Studio 필요)

1. **Android Studio 설치**: https://developer.android.com/studio
2. **프로젝트 열기**: Android Studio 실행 → `Open` → 이 `AdminMemoApp` 폴더 선택
3. Gradle Sync 자동 진행 (인터넷 필요). 안 되면 `File > Sync Project with Gradle Files`
4. **Build > Build Bundle(s)/APK(s) > Build APK(s)** → `app-debug.apk` 생성
5. 휴대폰에 설치 (출처를 알 수 없는 앱 설치 허용 필요)

## 전체 화면 구조

```
홈
├── 📖 본문학습      → 과목 선택 → 목록(검색/번호순, 순서 변경 가능) → 상세
│                      (제목/두문자/본문/암기정도★/메모/수정/음성읽기/Gemini질문)
├── 🗺️ 목차학습      → 과목 선택 → 목록 → 대목차→중목차→소목차→본문 드릴다운
├── ⏱️ 모의고사      → 과목(또는 전체 과목) 선택 → 문제수·시간 설정 → 실전 타이머
├── 🎲 학습퀴즈      → 과목 선택 → 8가지 유형이 매 문제 랜덤하게 섞여 출제
├── 🗂️ 학습내용관리  → 과목 선택 → [개념카드][두문자][두문자미등록] 탭
└── ⚙️ 설정          → 테마 / 글자크기 / 위젯 꾸미기 / Gemini API 키
```

## ⏱️ 모의고사 (신규, 하드코어 실전 모드)

과목 하나 또는 **"🌐 전체 과목 (4과목 랜덤)"** 을 골라서 시작합니다.

- **문제 수**(기본 4개, 1~8개)와 **제한시간**(기본 50분, 10~120분)을 슬라이더로
  직접 정할 수 있어요.
- 시작하면 바로 큰 숫자로 **카운트다운 타이머**가 돌아가고, 선택한 개수만큼
  주제가 "「◯◯◯」에 대하여 서술하시오." 형태로 화면에 쫙 뜹니다. 실제
  시험처럼 백지(종이)에 손으로 목차/답안을 써보는 용도로 만들었고, 원하면
  앱 안의 입력칸에 간단히 키워드만 타이핑해도 됩니다.
- **암기정도가 낮은 주제일수록 더 잘 뽑혀요** — 취약한 부분 위주로 실전
  감각을 기를 수 있어요.
- 시간이 다 되거나 "제출하고 모범답안 보기"를 누르면, 문제마다 **모범답안
  보기** 버튼이 생겨서 실제 본문 내용과 바로 비교할 수 있어요. 입력칸에
  적은 메모는 자동으로 그 주제의 메모(📝)에 시각과 함께 저장돼서 나중에
  본문학습에서 그때 뭐라고 썼는지 다시 볼 수 있어요.
- 본문학습 목록 화면에도 "⏱️ 이 과목으로 실전연습 시작" 버튼이 있어서
  바로 진입할 수 있어요.
- **지금은 본문학습의 주제 제목을 논점으로 사용**하고 있어요 (실제 기출
  문제만큼이나 서술형 학습에 좋은 소재예요). 실제 기출문제 PDF를 주시면
  그 문제은행을 모의고사에서 우선적으로 쓰도록 만들어드릴게요.

## 🗺️ 목차학습 (신규)

본문학습과 같은 순서로 주제 목록이 뜨고, 주제를 탭하면:

1. 처음엔 **대목차(1. 2. 3. ...)** 만 목록으로 보여줘요
2. 대목차를 탭하면 그 **중목차(1) 2) ...)** 들이 보여요
3. 계속 탭해서 내려가면 소목차(①, (1) 등)까지, 더 내려갈 게 없으면
   **실제 본문 내용**이 나와요
4. 상단 ✕ 아이콘이나 시스템 뒤로가기로 한 단계씩 올라갈 수 있어요

## 🎲 학습퀴즈 (기존 "두문자퀴즈"에서 이름 변경)

한 세션은 10문제이며, 문제마다 아래 **8가지 유형** 중 하나가 랜덤하게 나옵니다
(바로 이전 문제와 같은 유형은 연달아 나오지 않아요):

- 📝 객관식, 🔤 순서 배열, ⭕❌ OX, ✏️ 빈칸 채우기(두문자 글자),
  🔄 두문자로 주제 맞히기, 🧩 매칭 — 기존 6종
- **🔑 키워드 맞추기 (신규)**: 무작위 주제의 본문에서 중요 단어 1~3개를 가려요.
  가려진 단어가 2개 이상이면 각각 4지선다 객관식, **1개면 직접 타이핑하는
  주관식**이고 이땐 🎤 버튼으로 **음성 입력**도 가능해요(기기의 음성 인식
  기능 사용).
- **📚 목차퀴즈 (신규, 추천 기능)**: 목차 하나를 보여주고, ① 그것과 대등한
  다른 목차들을 고르거나 ② 그 하위 목차들을 고르는 문제예요. 선택지는
  정답 개수의 2배로 나오고, **정답만 맞히면 부분점수, 탭한 순서까지
  정답과 똑같으면 보너스 점수까지 받아요.**
- **🧭 문장→목차 찾기 (신규)**: 본문 속 문장 하나를 그대로 보여주고, 이
  문장이 대등한 목차들 중 어디에 속하는지 맞히는 객관식이에요. 목차퀴즈가
  "구조를 외우는" 연습이라면 이건 "본문을 읽으면서 지금 이게 몇 번
  목차 얘기인지 즉시 알아채는" 감각을 기르는 연습이라, 실전 서술형에서
  실제로 자주 쓰는 능력이에요.

**점수 체계**: 문제마다 배점이 달라요. 단순 객관식류는 1점, 키워드 맞추기는
빈칸 개수만큼(최대 3점), 목차퀴즈는 정답 개수+순서 보너스 1점까지 받을 수
있어요. 결과 화면에 "총점 X / Y점"으로 표시됩니다.

각 문제의 **"📖 본문 보기"** 버튼으로 원본 내용을 언제든 확인할 수 있어요.
(하위 목차의 두문자가 엉뚱하게 섞여 보이던 문제, 마지막 두문자의 본문이
목차 줄만 나오고 내용이 비어있던 문제 모두 데이터 생성 단계에서 고쳤어요.)

## ⭐ 암기정도 (신규)

본문학습 상세 화면에서 주제마다 **1~5단계 별점**으로 암기 정도를 직접
표시할 수 있어요. 낮게 표시한(잘 모르는) 주제일수록 **위젯과 학습퀴즈에
더 자주 나오도록** 가중치를 줬어요. 위젯에서도 별 표시를 탭하면 바로
순환(1→2→3→4→5→1)해서 바꿀 수 있어요.

## 🧩 위젯 꾸미기 (신규)

설정 화면에서 위젯의 **배경 색상**(7가지 프리셋), **투명도**, **글자 크기**를
바꿀 수 있고, 실시간 미리보기도 볼 수 있어요. 기본 크기는 4×4 셀이고 내용이
길면 안에서 스크롤됩니다.

## ✨ Gemini에게 질문하기 (신규)

본문학습이나 목차학습 화면에서 **본문 텍스트를 길게 눌러 드래그로 선택**하면
"✨ Gemini에게 질문" 메뉴가 떠요. 탭하면 질문 입력창이 뜨고, 답변도 이
다이얼로그 안에서 바로 보여줍니다.

**사용하려면 먼저 설정 화면에 Gemini API 키를 등록해야 해요**:
1. https://aistudio.google.com/apikey 에서 무료로 API 키 발급
2. 앱의 ⚙️ 설정 → "Gemini에게 질문하기" 항목에 키 붙여넣기 → 적용하기

키가 없으면 질문 시 설정 화면으로 안내하는 안내창이 떠요. (API 사용량에
따라 구글 쪽에서 과금될 수 있으니, 무료 한도를 확인해가며 사용해주세요 —
이 부분은 구글 정책이라 앱에서 제어할 수 없어요.)

## 🗂️ 학습내용관리

- **📄 개념카드**: 제목/본문 수정, 우측 하단 + 버튼으로 새 주제 추가(맨
  아래에 추가됨). 검색 중이 아닐 때 항목을 **길게 눌러 위아래로 끌면**
  순서를 바꿀 수 있고, 이 순서는 본문학습·목차학습에도 반영돼요.
- **🔑 두문자**: 기존 두문자 수정/삭제, 새 두문자 추가
- **➕ 두문자미등록**: 아직 두문자가 없는 주제에 새로 달아주기

## ⚙️ 설정

- 화면 테마(시스템/라이트/다크), 앱 글자 크기
- 위젯 배경색/투명도/글자크기
- Gemini API 키

## 카드 데이터

`app/src/main/assets/cards.json`에 기본 카드가 들어있습니다. 다른 과목
PDF를 올려주시면 같은 방식으로 변환해서 합쳐드릴게요.

## 알아두면 좋은 점

- 등급(A++/A+/A/B/C) 자동 인식과 두문자 추출은 PDF 원문을 정규식으로
  분석한 것이라 완벽하지 않을 수 있어요. 이상한 부분은 학습내용관리에서
  직접 고치시거나 알려주시면 재작업해드릴게요.
- 키워드 맞추기의 "중요 단어" 선정은 아주 단순한 규칙(조사 등 제외, 2~8자
  단어) 기반이라 가끔 애매한 단어가 나올 수 있어요.
- Gemini 기능은 인터넷 연결과 유효한 API 키가 필요합니다.
